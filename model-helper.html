📦 MediaPipe 模型下载器

本页面帮你把 hand_landmarker.task 模型文件下载到手机。下载完后在「文件」App 里确认文件名是 hand_landmarker.task（不是 .txt 或其他）。
方法一：直接下载（推荐先试）
方法二：如果方法一失败
复制下面地址到 Safari 地址栏，看能否下载：
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
如果浏览器显示 JSON 错误（403/denied），说明当前网络访问 Google Cloud 被拒。试方法三。
方法三：手动保存（终极办法）
如果上面都失败，需要一台能翻墙的电脑：
1. 电脑开 VPN/代理
2. 浏览器打开上面那个 .task 地址
3. 浏览器会下载一个 .task 文件
4. 通过微信/邮件/AirDrop 传到手机
5. 保存到「文件」App，确认文件名
下载完后的文件结构
hand-negative.html          ← 主程序
vision_bundle.mjs           ← JS模块(已下载)
hand_landmarker.task         ← 模型(正在下载)
wasm/                        ← WASM文件夹(已下载)
  vision_wasm_internal.js
  vision_wasm_internal.wasm
全部上传到 GitHub 仓库根目录后，等 1-2 分钟，打开主页面即可。
